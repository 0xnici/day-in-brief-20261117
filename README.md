Tuesday 17 November 2026 on one page: a newspaper front page that sums up the day's world news in a single image. The date is the headline; six panels carry the day's stories — US strikes on Qeshm Island and the burning tanker Tara Gas, the Ukrainian strike that closed part of the Crimean Bridge, the outage cascade across US airports, banks and big tech, the US losing measles elimination status, Trump at the Quad summit in Manila as leaders gathered in Shenzhen, and the push to open Gaza's crossings before winter — plus an "also today" strip for the rest. Every story and figure is that day's wire reporting, set in large serif type that stays readable at thumbnail size. The page was typeset by `tools/render.py`; `main.py` writes it, byte for byte, to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
