One page, one day: Tuesday 17 November 2026 as a newspaper front page. The date itself is the headline, and six panels below it carry the day in brief — US strikes on Qeshm Island with the tanker Tara Gas burning, the Ukrainian strike that closed part of the Crimean Bridge, cascading outages across US airports, banks and big tech, the US losing its measles elimination status, Trump at the Quad summit in Manila while leaders gathered in Shenzhen, and the push to open Gaza's crossings before winter — with an "also today" strip along the bottom for everything else. All of it is that day's wire reporting, set in large serif type that stays legible at thumbnail size. `tools/render.py` did the typesetting; `main.py` writes the finished page, byte for byte, to the output directory and verifies the copy against the original before it reports success.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
